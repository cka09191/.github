# Project Control Context

This repository owns project design, backlog, decision records, learning
records, and evidence pointers. It does not own product implementation.

- Keep product source, credentials, private assets, and raw transcripts out of
  this repository.
- Treat GitHub Issues as canonical tickets and update them through reviewable
  state transitions.
- Preserve `user-reserved-scope`. Agents may implement only the explicit
  `agent-support-scope` until the user changes ownership.
- Escalate cost, credentials, external accounts, deployment, publication,
  rights, and irreversible actions.
- Store verified facts, inference, information time, and evidence pointers;
  do not duplicate Git commit history in prose.
- Make repository changes on a feature branch and submit a pull request.
